# 07 - S3

Create a globally unique S3 bucket.

Recommended baseline:

- Block all public access.
- Enable encryption.
- Enable versioning if useful for the lab.
- Use the EC2 IAM role for access.

The sample application exposes `/api/storage-info` to show whether an S3 bucket is configured.

For a production upload workflow, generate pre-signed URLs or implement a controlled upload service. Do not make the bucket public just to serve uploaded files.
