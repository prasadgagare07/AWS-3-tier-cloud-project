# 04 - EC2

Launch two Linux EC2 instances.

Place:

```text
EC2-1 → Private-App-A
EC2-2 → Private-App-B
```

Attach `EC2-SG` and the IAM role.

## Administration

Because the instances are private, direct SSH from the internet is intentionally avoided in the final architecture.

For a beginner lab, you can temporarily use a controlled administration path such as AWS Systems Manager Session Manager, or a properly designed bastion/VPN solution.

Systems Manager is preferred over opening SSH broadly.

## Install Node.js

Use the current supported Node.js LTS method for your chosen Linux distribution.

Then copy the `application/backend` directory to each instance.

Create an environment file from `.env.example` and provide the RDS connection values securely.

Test locally on the instance:

```bash
npm install
npm start
```

In another shell:

```bash
curl http://localhost:3000/health
```

Expected result contains:

```json
{"status":"ok","database":"connected"}
```

For the two servers use different values:

```text
SERVER_ID=ec2-1
SERVER_ID=ec2-2
```

This makes it easy to demonstrate which instance answered a request.
